Technical details

Problem

Project 02

AI, computer vision, and research

Missing-Person Identification System

A facial recognition pipeline that helps identify potential matches for missing persons from CCTV footage. Published at IEEE ICCES 2025.

96.2% accuracy across varying conditions, with a minimal training set.

  1. MTCNNface detection
  2. FaceNet128-d embeddings
  3. SVMclassification
  • Python
  • TensorFlow
  • CNN
  • MTCNN
  • FaceNet
  • SVM
  • OpenCV
Technical details

Problem

Searching CCTV footage by hand is slow, and lighting and camera angles make face matching unreliable.

Implementation

Faces are detected with MTCNN, resized to 160 × 160, and converted into 128-dimensional FaceNet embeddings. An SVM classifier, with a label encoder, then performs the matching, and OpenCV handles the video frames.

Challenges and learning

Keeping matches reliable across angles and lighting, with a small training set, taught me how to evaluate and write up a technical result for publication.

GitHub repository

Project 03

Computer vision and human-computer interaction

GestureMotion Virtual Whiteboard

A touch-free virtual whiteboard. Hand gestures draw, erase, and recognise shapes on a digital canvas in real time.

95%+ accuracy across 15+ hand gestures.

  • Python
  • OpenCV
  • MediaPipe
  • NumPy
  • CNN gesture recognition
Technical details

Problem

Whiteboards usually need a mouse or touchscreen. Touchless drawing is a more natural way to present and brainstorm.

Implementation

MediaPipe tracks 21 hand landmarks, and the index fingertip (landmark 8) drives drawing. A CNN classifies alphabet gestures, and an OOP, event-driven architecture manages canvas state and a 500+ frame replay engine. Shape recognition covers 12+ shapes at 92% precision, and handwriting beautification gave a 30% improvement. Processing runs at 30 FPS.

Challenges and learning

Keeping per-frame work light enough for real time pushed me toward efficient algorithms and clean state management.

GitHub repository
